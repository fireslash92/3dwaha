# أسرار عين الوادي

لعبة مغامرات بأسلوب JRPG الكلاسيكي تجري في عالم عماني الطابع: استكشاف، وحوارات، ومعارك بالأدوار. أربعة فصول في عين الوادي تنتهي بعودة نجمة الوادي إلى السماء، ثم تبدأ رحلة القوافل إلى مدن جديدة (الفصل الخامس: شتاء جبال الغيم)، والمستويات حتى ٩٠.

تعمل في المتصفح مباشرة، وعلى الآيفون يمكن تثبيتها على الشاشة الرئيسية لتفتح بملء الشاشة وتعمل دون إنترنت. كل الرسومات والأصوات والموسيقى تُولَّد بالكود، فلا توجد ملفات صور أو صوت.

## تشغيلها على جهازك

افتح مجلد المشروع في الطرفية، ثم شغّل خادمًا بسيطًا:

```
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080` في المتصفح. لا يمكن فتح `index.html` بالنقر المزدوج، لأن المتصفح يمنع تحميل الملفات المتعددة من القرص مباشرة.

## تثبيتها على الآيفون

1. افتح رابط اللعبة المنشور في سفاري.
2. اضغط زر المشاركة، ثم «إضافة إلى الشاشة الرئيسية».
3. افتحها من أيقونتها. بعد أول فتح تعمل دون إنترنت.

## بنية المشروع

```
index.html              صفحة اللعبة (تُولَّد من tools/build.mjs، لا تعدّلها يدويًا)
manifest.webmanifest    بيانات التطبيق القابل للتثبيت
sw.js                   عامل الخدمة للعب دون إنترنت (يُولَّد تلقائيًا)
icons/                  أيقونات التطبيق
styles/main.css         كل التنسيقات
src/
  load-order.json       ترتيب تحميل الملفات (مهم: الملفات تعتمد على ما قبلها)
  markup.html           عناصر الواجهة: الحوار، القائمة، المتجر، شاشات البداية والنهاية
  core/                 الأدوات العامة، التصادم، الحالة، الشاشة، الإدخال، التحديث، الرسم، الحفظ
  art/                  رسم ناصر وأهل القرية والبيوت والأشجار والأثاث
  world/                القرية، البيوت، الغابة، الليل والنهار، الطقس، الحياة اليومية، وادي الفلج، الحصن القديم
  story/                أهل القرية وحواراتهم، تسلسل القصة، المهام الجانبية
  rpg/                  الخصائص والعتاد والمهارات، منحنى المستويات حتى ٩٠ والعتاد المتدرّج، البيسة والمتجر
  world/areas.js        محرّك المناطق الجديدة: يبني المدن والدروب والمغارات من إعدادات
  story/chapter5.js     الفصل الخامس: جبال الغيم
  story/chapter6.js     الفصل السادس: مستنقعات القرم
  world/diving.js       مهرجان الغوص على اللؤلؤ
  story/chapter7.js     الفصل السابع: مغارات الجن والآثار، والحلبة
  story/chapter8.js     الفصل الثامن: غابات الخريف، والترويض ومعرض الوحوش
  battle/               نظام المعارك والأعداء ونقاط الضعف والحالات
  audio/                المؤثرات والموسيقى المولّدة
  ui/                   القائمة الرئيسية، الخريطة الصغيرة، موسوعة المخلوقات
  boot.js               التشغيل
tools/build.mjs         يبني index.html و sw.js ونسخة الملف الواحد
tests/smoke.mjs         اختبار آلي يلعب الفصل الأول ومعركة ويختبر الحفظ
dist/                   نسخة الملف الواحد (لنشرها كـ Claude Artifact)
```

الملفات في `src/` سكربتات عادية تتشارك النطاق العام وتُحمَّل بالترتيب المكتوب في `load-order.json`. كل ملف يمكنه استخدام ما عرّفته الملفات قبله. الدوال المعرّفة في ملف لاحق تُستدعى فقط في أثناء اللعب، لا في لحظة التحميل.

## بعد أي تعديل

```
node tools/build.mjs
```

يعيد هذا الأمر توليد `index.html` و`sw.js` برقم نسخة جديد، فيحصل اللاعبون على التحديث بدل النسخة المحفوظة عندهم. ويولّد أيضًا `dist/ayn-alwadi.artifact.html`. لا يحتاج أي حزم.

لإضافة ملف جديد: أنشئه في `src/`، وأضف مساره في المكان المناسب من `load-order.json`، ثم شغّل البناء.

## الاختبار

يحتاج الاختبار إلى Playwright مرة واحدة:

```
npm install
npx playwright install chromium
npm test                 # يختبر نسخة الويب
npm run test:artifact    # يختبر نسخة الملف الواحد
```

## النشر على GitHub Pages

1. ارفع المشروع إلى مستودع على GitHub.
2. من إعدادات المستودع: Settings ← Pages ← Source: «Deploy from a branch»، ثم اختر الفرع `main` والمجلد `/ (root)`.
3. بعد دقيقة يصبح الرابط جاهزًا: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

تذكّر تشغيل `node tools/build.mjs` قبل كل رفع.
